# Общая информация
Инструкция содержит перечень необходимых для работы с Docs as Code утилит, а также описание процессов их установки или регистрации.
# Утилиты:
## Python
Язык программирования. В рамках курса необходим для установки генератора статических сайтов и работы с ним.
> __Установка__:
> 1. Перейти по ссылке.
> 2. Запустить скачанный файл.
> 3. Установить в папку по умолчанию, __не меняя__ опции установки.
## Git
Система контроля версий. В рамках курса необходима для работы с документацией и её хранения.
> __Установка__:
> 1. Перейти по ссылке.
> 2. Запустить скачанный файл.
> 3. Установить в папку по умолчанию, __не меняя__ опции установки.
## GitHub
Сайт для размешения проектов, основанный на системе контроля версий Git.
> __Регистрация__:
> 1. Перейти на сайт.
> 2. В правом верхнем углу нажать “Sign Up”.
> 3. Ввести данные в полях регистрации и нажать “Continue”.
> 4. Ввести код из письма, отправленного на указанный e-mail.
## Visual Studio Code
Бесплатный текстовый редактор кода для разработки веб-приложений.
> __Установка__:
>
> Перейти по ссылке и установить приложение.
## Командная строка
Текстовый интерфейс для взаимодействия с операционной системой и другим программным обеспечением с помощью команд
> Командная строка предустановлена по умолчанию.
# Проверка установки Python и Git
Чтобы проверить, корректно ли установлены утилиты Python и Git, необходимо:
1. Открыть командную строку.
2. _Последовательно_ ввести:
- `python --version`;
- `git --version`.

Если утилиты установлены корректно, в командной строке отобразятся их текущие версии.
